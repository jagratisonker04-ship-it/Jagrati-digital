# SmileCare Dental Studio — Jagrati Digital Portfolio Demo

A premium responsive dental-clinic landing page concept.

## Run
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save and wait for the Pages URL.

## Before showing as a real client website
Replace all demo details:
- clinic name/contact details
- dentist credentials and registration information
- address and map
- verified testimonials
- real services/pricing
- real appointment/WhatsApp integration
- image licenses/approved clinic photos

The current site intentionally identifies fictional/sample content where appropriate.
